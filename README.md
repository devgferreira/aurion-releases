# Aurion

Downloads do Aurion, o assistente de voz para o seu PC.

**[Baixar o Aurion para Windows](https://github.com/devgferreira/aurion-releases/releases/latest/download/Aurion-Setup.exe)**

1. Instale e abra o **Aurion**.
2. Entre com a sua conta (crie uma em https://aurion-dusky.vercel.app/cadastro).
3. Clique em **Instalar Aurion**: o launcher baixa, confere e abre o assistente, e mantém ele atualizado.

Aqui ficam só os arquivos de instalação.
